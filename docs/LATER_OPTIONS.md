# أوبشنز مؤجلة (مش ضمن النسخة الحالية)

الأوبشنز دي متسجلة عشان نرجعلها بعدين، ومش هتتنفذ دلوقتي. التركيز الحالي على نظام مستقر يتعتمد عليه.

## 1. النسخة المحلية (Desktop / On-Premise)
- نسخة تتشغل على جهاز العميل من غير إنترنت، بقاعدة بيانات محلية.
- فرع واحد فقط، وده الحد المعتمد للنسخة المحلية.
- التسعير المقترح: ترخيص مرة واحدة + دعم سنوي (الأسعار في المحادثة).
- محتاجة بناء مختلف (قاعدة بيانات محلية وحماية بيانات داخل الجهاز).

## 2. المحلي متعدد الفروع (سيرفر مركزي)
- سيرفر في المركز، والفروع بتتصل عن طريق VPN أو الإنترنت.
- مفيش مزامنة بين فروع منفصلة، فالحل ده أسهل من المزامنة.
- محتاج تطوير لنسخة تشتغل على سيرفر مركزي.

## 3. المزامنة Offline-First
- كل فرع يشتغل بدون إنترنت ويزامن مع السحابي لما يتصل.
- أصعب طريقة، وتحتاج اختبارات كتير جداً قبل البيع.

## 4. تسعير السحابي المتعدد الفروع الأرخص
- خطة "سحابي متعدد - أساسي" بسعر أقل للعملاء اللي عندهم فروع كتير وميقدروش يدفعوا الخطة المتقدمة.

## 5. إعدادات كل عميل (config.js)
- ملف إعدادات منفصل لكل عميل فيه رابط مشروع Supabase والمفتاح العام.
- كان متنفذ في v1.89 واتعكس بناءً على طلب، ولازم يتعاد بنفس الطريقة لما نبدأ نجهز أول عميل.
- دليل النشر (DEPLOY_CLIENT.md) كان جزء منه، ويتعاد معاه.

## 6. توحيد أسلوب الكود
- إعادة تنسيق كاملة للملفات.
- مؤجلة لأنها تغيير كبير يحتاج اختبار كامل قبل أي نشر.

## 7. تنظيف الإصدارات القديمة في الـ CSS
- أقسام الـ CSS المرقمة بأرقام الإصدارات (v1.77 وغيرها) تتجمع في ملف واحد منظم.
